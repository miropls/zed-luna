# Luna theme for Zed

A minimal, near-black Neovim colorscheme with a small set of warm and cool accents for keywords, functions, types, and strings — dark as a night sky, with just enough color to read by. Non-flat floats, full plugin coverage, and an accent option to desaturate syntax colors to taste, out of the box.
